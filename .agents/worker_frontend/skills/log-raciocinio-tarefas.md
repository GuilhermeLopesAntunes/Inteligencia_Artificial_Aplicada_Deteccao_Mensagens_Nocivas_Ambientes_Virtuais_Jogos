# Log de Raciocínio de Tarefas

## Regra fixa
Esta skill deve ser tratada como uma regra permanente: antes de começar a executar qualquer pedido do usuário, verifique/prepare o arquivo de log do dia. Depois de concluir a tarefa, registre nele o raciocínio que você de fato usou para chegar à resposta/ação — não apenas um resumo do resultado.
Pasta: C02 CLAUDE OBSIDIAN/Logs e Memória/Logs de Raciocínio/
Nome do arquivo: log-YYYY-MM-DD.md
